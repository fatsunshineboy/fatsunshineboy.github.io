# 欢迎来到我的博客

这是我的第一篇博客文章。创建这个网站的灵感来源于游戏《死亡搁浅》(Death Stranding)。

## 网站特色

- **Death Stranding 主题设计**：采用游戏中经典的黑色、金色配色方案
- **响应式布局**：支持桌面端和移动端
- **博客系统**：记录学习和成长
- **图片墙**：展示精美的游戏截图
- **工具集合**：提供实用的开发工具

## 技术栈

- Vue 3 Composition API
- Vite 5 构建工具
- Vue Router 4
- 自定义 CSS 框架

## 关于我

我是一名前端开发者，热爱技术分享和创新设计。这个网站是我个人学习和探索的结晶。

感谢你的访问，希望这个网站能对你有所帮助！
